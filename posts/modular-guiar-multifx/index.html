Analog Guitar Multi-FX

Maciej Rogoż
2 Jan 2024
analog-electronics, pcb-design, audio, guitar-fx, hardware

A modular analog guitar multi-effect integrating an entire signal chain.

Project Overview

This project focuses on building a versatile, modular analog signal processor for electric guitar.

  • Multifx v1: A simplified prototype with hand-etched PCBs serving as the testing foundation for modular routing and relay logic.
  • Multifx v2 (In Progress): An upgraded modular architecture featuring commercially fabricated PCB boards and refined signal path switching.

Key Features

  • Relay-Controlled Routing: True-bypass switching system for dynamic effect chain configuration.
  • Custom Analog Circuits: Integrated distortion and modulation stages on dedicated circuit boards.
  • Role: Analog Circuit & PCB Design, Enclosure Assembly
