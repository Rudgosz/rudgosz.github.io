Educational Processor PCB Board

Maciej Rogoż
1 Jan 2026
pcb-design, digital-logic, hardware, kicad

An educational PCB designed for the AGH Logic Unit research group that demonstrates fundamental processor architecture and real-time data flow using interactive hardware visualization.

Project Overview

The board allows physical tracing of signals between memory, registers, and the ALU. All operations are controlled manually via switches and push-buttons, with logic states visualized in real time across different functional blocks using LEDs.

Key Functional Blocks

  • Register File: Implemented as a 4x4 LED matrix representing four 4-bit registers, allowing direct observation of data distribution and manual pattern creation.
  • ALU (Arithmetic Logic Unit): Asynchronous unit performing bitwise operations (AND, OR) on data fetched from selected source registers.
  • Instruction & Data Memory: LED indicators displaying current input configurations, opcodes, and final execution results.
  • Manual Control Interface: Dedicated switches for data line inputs (DATA [3..0]), register selection (R SET, REG 0, REG 1), write triggers (WE), and asynchronous system reset (RST).
  • Role: Schematic & PCB Layout Design
  • Organization: AGH Logic Unit Student Research Group
