Arduino-Based Sim Racing Pedals

Maciej Rogoż
1 Jan 2023
arduino, 3d-printing, usb-hid, hardware

A custom 3D-printed USB sim racing pedal set combining Arduino microcontroller logic.

System Architecture

  • Interface: Emulates a USB Human Interface Device (HID) for game compatibility.
  • Control: Arduino microcontroller processing input signal.
  • Mechanical Structure: Custom 3D-printed pedal arms and mounting framework.
